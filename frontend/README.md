# 🚆 RailETA AI Frontend

Next.js frontend interface for the RailETA AI Platform.

## 🔗 Localhost Page Links

| Page | Localhost URL | Description |
| :--- | :--- | :--- |
| 🏠 **Home Page** | [http://localhost:3000](http://localhost:3000) | Landing page & portal selector |
| 🧑‍🤝‍🧑 **Passenger Portal** | [http://localhost:3000/passenger](http://localhost:3000/passenger) | Real-time train ETA search & live tracking |
| 🛠️ **Control Room** | [http://localhost:3000/control-room](http://localhost:3000/control-room) | Network control dashboard |
| 📊 **Analytics** | [http://localhost:3000/analytics](http://localhost:3000/analytics) | Delay charts & performance analytics |
| 🎮 **Simulation** | [http://localhost:3000/simulation](http://localhost:3000/simulation) | Live train movement simulator |

## 🚀 Running the Frontend

```bash
# Install dependencies
npm install

# Start development server on localhost:3000
npm run dev
```
